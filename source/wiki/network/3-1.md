> [用户材料] 001 局域网、共享链路和卫星可靠传输；002 DHCP/ARP；004–005 跨层封装。强化课并未单独重讲本小节所有基础定义，以下整理用于理解后面各节的实际功能。

链路层的对象是**当前链路上的数据交付**。物理层送来信号/比特，数据链路层按相应协议组织帧、识别本次链路接收者、处理必要的校验，并在共享介质上根据协议协调发送。

| 功能 | 课中的实例 |
|---|---|
| 成帧 | IP数据报封装到以太网帧或802.11数据帧 |
| 链路寻址 | 以目的MAC确定本次帧交付对象；ARP辅助解析下一跳MAC |
| 介质访问 | 共享以太网的CSMA/CD、无线的CSMA/CA |
| 差错检测 | 帧尾FCS |
| 有条件的可靠传输、流量控制 | 卫星链路上的GBN/SR及无线逐帧ACK；不是所有链路协议一律提供可靠服务 |

路由器转发时拆掉入链路的帧、检查网络层目的IP，选择出接口或下一跳，再按出链路的协议重新封装。普通交换机只需处理链路层的源、目的MAC等信息，不承担跨IP子网的路由。

**重点**：链路层的一跳交付与网络层的端到端寻址有区别。接收了物理信号也不表示已经向上交付帧，更不表示上层进程收到消息。进一步看[交换机](/408-network-notes/wiki/network/3-8/)与[封装](/408-network-notes/wiki/network/1-2/)。
